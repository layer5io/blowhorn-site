How you run it

Amplify on autopilot

3 ways in, 1 engine. Every command has a read-only or dry-run form, so you rehearse a run before anything is published.

  • Menu-bar app

    The popover shows what is due, running and about to post. The console covers jobs, content, runs, profiles, analytics, the service and settings. See the app, screen by screen.

  • CLI

    The engine behind everything. Each command carries its own help and a worked example, with the preview form first. See the documented CLI.

    blowhorn post --profile all --dry-run

  • Background service

    A background service checks the queue every 10 minutes and runs what is due, with the app closed and nobody watching. Keep posting when the app is closed.

  • Chrome extension

    LinkedIn, X, Reddit and Hacker News actions run inside your own signed-in Chrome through the Blowhorn extension. GitHub, Bluesky and Slack go through their APIs. What it does on each platform.

Trust

Yours to keep

Blowhorn runs as many public voices as you need without handing the keys to anyone else.

  • Your LinkedIn, X, Reddit and Hacker News browser sessions stay on your Mac

    Those sessions stay in your own Chrome, where the Blowhorn extension acts for you. Credentials you give Blowhorn for GitHub and Hacker News, and a Slack workspace session you choose to link, are kept in your organization's store on Layer5 Cloud (see the privacy page).

  • Your organization's store, on Layer5 Cloud

    The queue, schedule, profiles, run ledger and platform tokens live in a database scoped to your organization on Layer5 Cloud. Every row carries your organization's id. See where your data lives.

  • Hacker News: submit and comment only

    Blowhorn submits stories and posts comments on Hacker News. It never votes, and it holds each profile to 2 link submissions a day. Post to Hacker News.

Control

You're in control

Blowhorn is built for AI, but the AI is never in control. You are. Any given Blowhorn install only runs one automation on a given platform for a given profile at a time, because no human types into two browser windows at once.

  • Will I get banned?

    Nobody can promise that for any tool, and we won't. Blowhorn types and clicks at a human pace you choose, caps its own X follows and Hacker News submissions, and never solves a CAPTCHA for you. How Blowhorn paces itself.

  • Will it post twice?

    It clicks once per action. Within a run, Blowhorn doesn't retry a failed post; it moves on to the next item. If a post goes out but Blowhorn can't record it, it stops that profile's queue rather than risk posting twice. Scheduled jobs only re-run a failure if you turn on retries, and they're off by default. A send it couldn't confirm is held for you. Your Macs coordinate through one queue, so the same post isn't sent from two of them. How Blowhorn avoids repeat posts.

  • What if an AI agent is driving?

    Agents use the same queue and CLI you do, under the same built-in limits. Only approved posts go out, and a dry run or a pause is always one command away. Pause and resume posting.
